# 🌱 Smart Agri Tech – AI Powered Farming Assistant

Smart Agri Tech is an intelligent agriculture web platform designed to help farmers make data-driven decisions using Machine Learning and Remote Sensing insights. The system provides crop recommendations, fertilizer suggestions, and crop yield prediction to improve productivity and support sustainable farming.

The platform integrates AI models, environmental data, and multilingual support to make smart farming accessible to farmers in different regions.

---

## 🚀 Key Modules

### 🌾 1. Crop Recommendation System

Predicts the most suitable crop based on:

* Soil nutrients (N, P, K)
* Temperature, humidity, rainfall, pH
* Uses hybrid stacked ensemble ML models

---

### 🧪 2. Fertilizer Recommendation System

Suggests optimal fertilizers based on:

* Soil condition
* Crop type
* Nutrient deficiencies

---

### 📈 3. Crop Yield Prediction

Estimates expected crop yield using:

* Remote sensing data (NDVI, SAVI, rainfall)
* Tamil Nadu government agricultural data
* Machine learning regression models

---

### 🤖 4. Explainable AI (XAI) Module

Provides transparency for predictions using:

* Feature importance
* SHAP explanations
* Local and global model interpretation

---

### 🌍 5. Multilingual Support

Supports multiple languages for farmers:

* English
* Tamil
* Hindi
* Kannada
* Telugu

## ⚙️ How to Run the Project

Follow these steps to run the website locally:

### Step 1: Clone the Repository

```bash
git clone https://github.com/UdhyaKumarKMIT/Smart-Agri-Tech
```

---

### Step 2: Navigate to Project Folder

```bash
cd Smart-Agri-Tech
```

---

### Step 3: Install Dependencies

```bash
npm i
```

---

### Step 4: Start Development Server

```bash
npm run dev
```

The app will start with auto-reload and instant preview.
